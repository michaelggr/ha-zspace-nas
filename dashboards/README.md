# 极空间面板

一套 Lovelace 配置，四个视图：

| 视图 | 内容 |
| --- | --- |
| 概览 | 运行时长 / 容器数、CPU·内存·温度·风扇·网络六宫格、存储池条形图、磁盘表格（温度/通电/重映射/健康）、下载概况 |
| 容器 | 运行中 / 已停止两组开关、磁盘健康 |
| 趋势 | CPU·内存·存储池使用率 24 小时曲线、网络收发曲线 |
| 全部实体 | 按类型分组列出全部实体（传感器 / 二进制 / 开关按钮），方便逐个核对 |

## 为什么不用写 entity_id

面板里的数值全部用 Jinja 从 `integration_entities('zspace_nas')` 里按**实体名称**取，
所以不管 HA 把 entity_id 生成成什么样都能用，你重命名实体时才需要跟着改模板。

## 方式一：UI 新建（推荐，不用改配置、不用重启）

1. 设置 → 仪表盘 → **添加仪表盘**
   - 标题：`极空间`
   - URL：`zspace`
   - 选「从空白开始」
2. 打开这个面板 → 右上角铅笔 → 右上角三个点 → **原始配置编辑器**
3. 把 `dashboards/zspace/dashboard.yaml` 整段粘进去 → 保存

新建的仪表盘默认就在侧边栏，点「极空间」进去后顶部有四个页签，可以逐个翻。

## 方式二：YAML 模式（侧边栏固定入口，重启生效）

1. 把 `dashboards/zspace/dashboard.yaml` 复制到 HA 的 `/config/zspace/dashboard.yaml`
2. 打开 `/config/configuration.yaml`，把 `dashboards/sidebar.yaml` 里那段 `lovelace:` 贴到末尾
3. 重启 Home Assistant

之后侧边栏会出现「极空间」，图标 `mdi:nas`。YAML 模式的好处是配置跟文件走，可以进 Git；
代价是改完要重启（或重载 YAML）才生效。

## 依赖

- 「趋势」「容器」「全部实体」三页用到 HACS 前端卡片 **auto-entities**
  （HACS → 前端 → 搜 `auto-entities` → 下载，刷新页面即可，不用重启）。
- 「概览」页零依赖，不装卡片也能看。

## 前提

- 集成已添加（设备与服务里能看到「极空间」）；
- 想在容器页操作开关：「集成 → 配置」勾选「允许容器控制」，「允许控制的容器」填 `*` 或具体名字。
  不填就没有开关，只有监控。

## 调整建议

- **存储池超过 85% 变红**：模板里 `{% if pct > 85 %}var(--error-color)`，按需改阈值。
- **容器太多**：容器页已按状态分组；想再过滤就在 auto-entities 的 `filter.include` 加
  `entity_id: "*qbittorrent*"` 之类条件。
- **按房间分组**：把 NAS 设备分配到区域后，可直接用内置「区域」卡片。

## 已验证

用真实字段结构造的 30 个假实体跑过渲染：8 张模板卡 0 失败，
存储池合计、磁盘健康判断、容器计数都对得上。真机上某个数值显示 `—` 时，
多半是实体名被改过，同步一下模板里的中文关键词即可。
