# 极空间面板

一套 Lovelace 配置，三个视图：

| 视图 | 内容 |
| --- | --- |
| 概览 | 运行时长 / 容器数、CPU·内存·温度·风扇·网络六宫格、存储池条形图、磁盘表格（温度/通电/重映射/健康）、下载概况 |
| 容器 | 运行中 / 已停止两组开关、磁盘健康 |
| 趋势 | CPU·内存·存储池使用率 24 小时曲线、网络收发曲线 |

## 为什么不用写 entity_id

面板里的数值全部用 Jinja 从 `integration_entities('zspace_nas')` 里按**实体名称**取，
所以不管 HA 把 entity_id 生成成什么样都能用，你重命名实体时才需要跟着改模板。

## 前提

1. 集成已添加（设备与服务里能看到「极空间」）；
2. 想在「容器」页操作开关的话，集成 → 配置 → 勾选「允许容器控制」，
   「允许控制的容器」填 `*` 或具体名字。不填就只有监控、没有开关。

## 安装卡片依赖（只有趋势页需要）

HACS → 前端 → 搜索 `auto-entities` → 下载。不用重启，刷新浏览器即可。

不装也能用：把 YAML 里 `type: custom:auto-entities` 的三块删掉，概览页完全不受影响。

## 导入

1. 设置 → 仪表盘 → **添加仪表盘** → 新建仪表盘
   - 标题：`极空间`
   - URL：`zspace`
   - 选「从空白开始」（不要用默认概览）
2. 打开这个新面板 → 右上角铅笔（编辑）→ 右上角三个点 → **原始配置编辑器**
3. 把 `zspace-dashboard.yaml` 的内容整段粘进去 → 保存

想放到侧边栏的话，这个面板创建后会自动出现；想改图标/顺序在面板编辑里调。

## 调整建议

- **存储池超过 85% 变红**：模板里 `{% if pct > 85 %}var(--error-color)`，按需改阈值。
- **容器太多**：「容器」页按状态分了运行中/已停止；想再过滤就在 auto-entities 的
  `filter.include` 里加 `entity_id: "*qbittorrent*"` 之类的条件。
- **想按房间分组**：把 NAS 设备分配到区域后，可直接用内置「区域」卡片，不必用这套模板。

## 已验证

用真实字段结构造的假实体跑过一遍模板渲染（7 张模板卡，0 失败），
存储池合计、磁盘健康判断、容器计数都对得上。真机上如遇某个数值显示 `—`，
多半是实体名被改过，把模板里的中文关键词同步一下即可。
